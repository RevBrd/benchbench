# BenchBench

Official repository for **BenchBench: A Recursive Evaluation Framework for Benchmark Construction
Capability**.

**[Read the paper →](https://revbrd.github.io/benchbench/)**

BenchBench measures a model's ability to construct benchmarks on which it outperforms all other
models. Validity is enforced through adversarial peer review by rival contestants.
